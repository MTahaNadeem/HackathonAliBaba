# CourseCompass AI visual system

Audience: students in Pakistan exploring an uncertain next chapter. Primary task: choose the next useful step.

Thesis: a calm personal atlas, with a connected degree → career → skills map as the signature interaction.

Tokens: midnight #142D52; cobalt #3264D6; mint #CEF3E2; canvas #F5F7FB; white #FFFFFF; ink #172B48. Display uses Plus Jakarta Sans, body uses DM Sans with system fallbacks. Rounded 18–24px primary panels, 12px controls; generous 24–32px gutters; 16px body, 14px labels, 12px secondary metadata. Main working area pairs a spacious progress/path panel with a narrow adviser invitation. Sidebar is quiet, with clear active rail.

Critique: avoided a generic numeric dashboard and broad marketing hero. The path diagram encodes actual product stages. Mint indicates a next step, not arbitrary success. No pretend statistics or invented student endorsements. No image is needed for this tool: typography and the functional diagram carry the identity.

UX guidance: skill priorities applied for contrast, visible focus, large targets, mobile drawer and clear empty/error states. The skill search script could not run because Python is not installed; guidance is from the skill's explicit priority rules rather than a claimed database match.
